# 週課表檢視 — 設計補充

日期：2026-11-25
狀態：已定案（使用者於 2026-11-25 確認）
修改對象：`2026-11-24-lab-scheduler-design.md` 的 4.3（值班表）、4.5（行事曆）、4.6（老師可約時段）

## 使用者確認的決定

- 行事曆只顯示一週（週一～五 × 第 1～8 節）的課表格子，上方標示該週日期範圍（例：`2026/11/23（一）～ 11/27（五）`），可切換上一週／本週／下一週。行事曆只能看，不能改。
- 「我的值班」（老師為「我的可約時段」）是選擇「可以上班的節次」的地方，不是請假頁。
- 以整學期每週固定為主；某一週可以單獨調整，不影響其他週（使用者選 A）。
- 點格子直接跳出視窗。
- 所有時間以 24 小時制顯示與輸入（例 `13:10–14:00`）。

## 行為

### 我的值班／我的可約時段
- 上方：`‹`、`本週`、`›` 與該週日期範圍。
- 格子：週一～五 × 第 1～8 節，每格顯示那一天那一節的實際狀態（可以上班／不行），並標出與每週固定班表不同的格子（「本週調整」小標記）。
- 點任一格跳出視窗：
  - 目前可以上班：`只有這週不行`、`每週這節都不行`、`取消`。
  - 目前不行：`只有這週可以`、`每週這節都可以`、`取消`。
  - 若該格是本週調整過的，另有 `恢復成每週固定`。
- 已過去的日期、停課日、不在目前學期內的日期：只能看不能改（灰色）。
- 任何會讓已約好會議變得不可行的變更，沿用「先警告、再取消」流程。

### 行事曆
- 同樣的週切換與日期範圍。
- 每格顯示那一節實際在場的研究生（套用每週固定與單週調整）、與當節的會議（`會議：姓名`，待確認者加「（待確認）」）。
- 停課日整欄灰色並顯示原因；整天無人（且非停課日、在學期內）整欄紅色。
- 點格子沒有動作。原本的月檢視移除。

### 24 小時制
- 節次時間顯示一律 `HH:MM–HH:MM`（24 小時）。
- 管理頁節次時間的輸入改為 `HH:MM` 文字欄位（驗證 00:00–23:59），不使用會依語系顯示上午／下午的 `type=time`。

## 資料（我的決定）

- 新增「單週額外可以上班」：`slot_exceptions` 加欄位 `kind`（`'off'` 預設、`'extra'`）。`is_present` 改為：（每週固定有 且 無 `off` 例外）或 有 `extra` 例外；整天 `off`（period 為 null）仍優先於 `extra`。
- 新 RPC：`set_day_slot(p_date date, p_period smallint, p_on boolean, p_confirm boolean default false) returns jsonb`：依每週固定班表新增／刪除 `off` 或 `extra` 例外，使該日該節變成 `p_on`；回傳 `{applied, affected}`；`p_on=false` 時檢查受影響預約。`clear_day_slot(p_date date, p_period smallint, p_confirm boolean default false) returns jsonb`：恢復成每週固定（若因此變成不在，同樣先警告）。只有 active 老師／研究生可呼叫；過去日期、停課日、學期外拒絕（`NOT_EDITABLE`）。
- 依 grants 規則，新函式在 migration 裡明確 `grant execute ... to authenticated`。
- 既有 `add_exception` / `remove_exception` 保留但前端不再使用。

## 非目標
- 每週分開填（使用者選 A）。
- 行事曆上請假或編輯。
